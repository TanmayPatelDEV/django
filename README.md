# Django Login & CRUD Project

## Description
This project is a Django-based web application that provides user authentication and CRUD (Create, Read, Update, Delete) operations with search and logout functionality.

## Features
- Login system
- CRUD operations
- Search functionality
- Logout system

## Run

pip install django  
python manage.py migrate  
python manage.py runserver  

Open browser and go to:  
http://127.0.0.1:8000/
